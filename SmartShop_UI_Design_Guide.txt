২. Typography — লেখার নিয়ম
Font: Inter (Google Fonts থেকে load করো)। না পেলে system-ui বা sans-serif।

// index.html এ <head> এ দাও
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap" rel="stylesheet">

// tailwind.config.js এ
fontFamily: { sans: ['Inter', 'system-ui', 'sans-serif'] }

Page Title (H1)
text-2xl font-bold text-gray-800   →  24px Bold
Section Title (H2)
text-xl font-semibold text-gray-700   →  20px Semibold
Card Title
text-base font-semibold text-gray-800   →  16px Semibold
Body Text
text-sm text-gray-600   →  14px Regular
Label / Caption
text-xs text-gray-500   →  12px Regular
Number / Amount
text-lg font-bold text-gray-900   →  18px Bold
Code / ID
font-mono text-sm text-purple-600   →  14px Mono

৬. AI কে কীভাবে বলবে (Prompt Guide)
এই docs টা AI কে দিয়ে বলো — সে সুন্দর UI বানিয়ে দেবে।

Template Prompt — যেকোনো Page এর জন্য
// এই format এ AI কে বলো:

আমি SmartShop এ [page name] page বানাতে চাই।

Design rules:
- Font: Inter, Tailwind CSS use করো
- Color: Primary blue = #1A56DB, Page bg = bg-gray-50
- Cards: bg-white rounded-xl border border-gray-100 shadow-sm
- Buttons: bg-blue-600 hover:bg-blue-700 text-white rounded-lg
- Layout: Sidebar (w-56) + Main content (p-6)

এই page এ লাগবে:
- [specific feature 1]
- [specific feature 2]

SmartShop_UI_Guide.docx এর instruction follow করো।
React + Tailwind CSS এ বানাও।

Specific Page Prompts

Dashboard Page Prompt
Dashboard page বানাও। উপরে 4 টি stats card (Today Orders, Revenue, Pending, High Risk)।
নিচে 2 column: বামে Recent Orders table, ডানে Suspicious Orders list।
Color: blue border-left stats cards। Risk orders এ red highlight।
Data props দিয়ে আসবে। Loading skeleton দেখাও।

New Order Form Prompt
New Order form বানাও। Left side: form (customer info + order details sections)।
Right side: sticky Risk Analysis panel — score circle + reasons list।
Phone number দিলে customer auto-search হবে। Risk score real-time update হবে।
Submit এ loading state দেখাবে। Success এ toast notification দেখাবে।

Order List Page Prompt
Orders list page বানাও। উপরে search bar + status filter buttons।
Table: Order ID, Customer, Product, Amount, Payment, Status badge, Risk badge, Date।
Row click করলে detail page এ যাবে। Empty state দেখাবে।
Pagination নিচে। প্রতি page এ 20 orders।



এই guide follow করলে SmartShop হবে professional ও eye-catching।
